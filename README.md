# L2 Day 8 — Persona Modeling Fundamentals

Learn how role, tone, constraints and audience change agent behaviour. A persona is an operating specification—not merely a name or fictional biography.

Run `persona.py`, followed by `02_persona_comparison.py`. The reusable module uses a valid importable filename.

## Lab

Create a code-review persona, add forbidden behaviours, compare the same answer across two audiences, and design five persona evaluation questions.
