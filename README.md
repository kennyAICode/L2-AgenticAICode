# L2 Day 10 — Knowledge Base and Human-in-the-Loop Foundations

This first knowledge-base day builds transparent keyword retrieval before embeddings. The grounded QA flow shows retrieved evidence, creates a TinyLlama draft and pauses for approval.

Run `keyword_retriever.py`, followed by `02_grounded_qa.py`.

## Lab

Add five facts, show retrieval scores, reject unsupported questions, record reviewer decisions in JSON, and explain the difference between retrieval and generation.
