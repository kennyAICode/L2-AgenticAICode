# L2 Day 6 — Graph-Based Agent Workflows

## Outcomes

- Represent agent steps as nodes and transitions as edges.
- Pass typed state through a workflow.
- Implement deterministic and conditional routing.
- Understand the ideas used later by LangGraph without hiding them behind a library.

## Run from this folder

```powershell
python 01_graph_engine.py
python 02_conditional_graph.py
```

## Lab

Add a `review` node, protect the graph from cycles, log every state transition, and draw the resulting workflow.
